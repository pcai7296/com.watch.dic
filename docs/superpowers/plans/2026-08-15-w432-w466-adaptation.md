> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Copy w336's complete UI layout and all accumulated logic fixes into w432 (432×514 rect) and w466 (466×466 circle, safe-square 330×330), producing two resolution-ready branches whose UX and business logic match w336 pixel-for-pixel after scaling.

**Architecture:** w336 is the canonical branch (336×480 rect, all logic fixes applied). w432 scales w336's layout by factor 1.2857× horizontally (432/336) and 1.0708× vertically (514/480). w466 uses an inscribed safe-square of side 330px centered at (233, 233) inside the 466×466 circle, effectively a near-1:1 scale from w336 with extra symmetric padding. Both branches keep their hardcoded `app.ux` screen config (W432: rect 432×514; W466: circle 466×466).

**Tech Stack:** Vela QuickApp (.ux + CSS + JS), aiot-toolkit 2.0.4, @system.* native APIs.

- w432 X scale from w336 = **432/336 = 1.2857** (round to nearest integer).
- w432 Y scale from w336 = **514/480 = 1.0708** (round to nearest integer).

- Every commit message must include the branch tag: `feat(w432): ...` or `feat(w466): ...`.
